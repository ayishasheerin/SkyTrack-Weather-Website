# SkyTrack 🌦️

A simple weather application built using React. Search for any city and get its current weather information.

## About the Project

SkyTrack is a beginner React project created to learn how to build a website using React, CSS and API integration.

## Features

- Search weather by city name
- Display current temperature
- Show minimum and maximum temperature
- Display weather conditions using emojis
- Humidity and wind speed
- Feels-like temperature
- Atmospheric pressure
- Visibility
- Cloud coverage
- Wind direction
- Sunrise and sunset timings
- Responsive design
- Error message for invalid city names

## Technologies Used

- React.js
- JavaScript
- CSS
- Axios
- OpenWeatherMap API



## API

Weather information is fetched using the [OpenWeatherMap API](https://openweathermap.org/api).

- Handling user input
- Fetching API data using Axios
- Displaying dynamic data
- Handling errors
- Making responsive layouts using CSS
